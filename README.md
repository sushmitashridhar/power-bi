📊 Power BI Dashboard
I have created my own Power BI dashboard to analyze and visualize data effectively. This dashboard provides interactive insights and helps in decision-making by leveraging Power BI’s powerful analytics capabilities.

🚀 About My Dashboard
Purpose: HR Analytics dashboard
Data Sources: Excel
Key Visuals: Includes charts, graphs, KPIs, and filters for better data exploration.
Features:
Dynamic and interactive visualizations
Data filtering and drill-through capabilities
🛠️ Tools & Technologies Used
Power BI Desktop – For designing and creating the dashboard
Power BI Service – For publishing and sharing reports
Power Query – For data transformation and modeling
DAX (Data Analysis Expressions) – For custom calculations and measures
